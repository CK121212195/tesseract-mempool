# 🌌 Tesseract Mempool

未承認トランザクションの混沌（メンプール）を、四次元超立方体（テサラクト）の概念で視覚化するプロジェクトです。

## 📝 概要
ビットコインのブロックチェーンに刻まれるのを待つデータの生き物、それがメンプールです。tesseract-mempoolは、その多次元的なデータの流れを幾何学的な3D空間に投影する、芸術的かつ実用的なビジュアライザーです。

## 🚀 特徴
- 👁️ 従来の2Dグラフとは一線画す、サイバーパンクで多次元的なデータ表現
- ⛓️ 未承認取引のダイナミズムをアートとして体感できるUI
- 💻 起動しておくだけで部屋がラボのようになるギーク向けデザイン
